# Как страница уезжает в интернет (GitHub Pages)

Сам деплой делает агент по промпту [`prompts/deploy-persona.md`](prompts/deploy-persona.md).
Здесь объяснение, что при этом происходит, и что делать, если ссылка не открывается.

Слова `main`, `commit`, `push`, `origin`, `prod` разобраны в [`git-workflow.md`](git-workflow.md).
Если что-то звучит незнакомо, начни оттуда.

---

## Что делает агент

1. **Проверяет вход в GitHub.** Ты залогинился ещё на занятии 1 (промпт
   [`github-cli-setup.md`](https://github.com/ahtlv/claude-course-lesson-1/blob/main/prompts/github-cli-setup.md)),
   поэтому пароль никто не спросит.
2. **Заводит репозиторий.** Папка `work/Persona` становится git-репозиторием, а на GitHub
   появляется его копия (`origin`). Это заодно и страховка: если на компьютере что-то
   сотрётся, проект восстановится с GitHub.
3. **Отправляет страницу** коммитом в ветку `main`.
4. **Включает GitHub Pages.** GitHub берёт файлы из `main` и раздаёт их как сайт по адресу
   `твой-ник.github.io/имя-репозитория`. Сборки нет: у нас чистый HTML.
5. **Проверяет, что сайт собрался,** и показывает ссылку.

### Почему репозиторий публичный

Бесплатный GitHub Pages работает только с публичными репозиториями, приватные Pages есть
только на платных тарифах. Для страницы, которую и так собираешься показывать людям, это
обычно не проблема. Но решение должно быть сознательным: если страница уже про тебя, там
твоё имя и фото.

### Автодеплой

После первого раза настраивать больше ничего не нужно. Каждый push в `main` сам обновляет
сайт примерно за минуту.

## Если что-то пошло не так

- **По ссылке 404 «There isn't a GitHub Pages site here».** Первая сборка занимает минуту-две,
  подожди и обнови. Не помогло, попроси агента:

  ```text
  Проверь, запускалась ли хоть одна сборка GitHub Pages в моём репозитории.
  Если ни одной, сделай пустой коммит и запушь, чтобы её запустить.
  ```

  Это известная особенность GitHub: Pages включён, в настройках всё выглядит правильно, но
  первая сборка не стартовала. Её запускает следующий push.
- **Страница открывается пустой или без стилей и картинок.** Скорее всего, `index.html`
  лежит не в корне репозитория или пути к картинкам указаны от твоего компьютера. Попроси
  агента проверить структуру и пути.
- **При push просят логин и пароль.** Вход с занятия 1 слетел. Пароль от GitHub здесь не
  сработает, это не баг: GitHub давно отключил такой вход. Отправь агенту промпт
  [`github-cli-setup.md`](https://github.com/ahtlv/claude-course-lesson-1/blob/main/prompts/github-cli-setup.md)
  из занятия 1 ещё раз.
- **«Команда не найдена» для `git` или `gh`.** Перезапусти VS Code целиком. Не помогло, тот же
  промпт из занятия 1 поставит недостающее.
- **Изменения не появились на сайте.** Спроси агента: «Мои изменения точно отправлены в main
  на GitHub? Проверь и покажи статус последней сборки Pages».
