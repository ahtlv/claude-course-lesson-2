# Выкладываем страницу Persona в интернет

**Когда:** в конце занятия 2, когда страница Persona собрана и проверка в начале занятия
показала твой ник на GitHub.
**Что делает:** агент сам заводит репозиторий на GitHub, отправляет туда страницу, включает
GitHub Pages, проверяет, что сайт реально собрался, и показывает живую ссылку. Руками в
настройках GitHub ничего не кликаешь.
**Как использовать:** в VS Code открыта папка `work`, отправь Claude Code промпт ниже и отвечай
на вопросы агента.

> ⚠️ Репозиторий будет **публичным**: бесплатный GitHub Pages работает только так. Если ты уже
> переписал страницу под себя, там твоё настоящее имя и фото. Агент спросит подтверждение
> перед публикацией.

```text
Выложи мою страницу Persona в интернет через GitHub Pages. Работаем только
с папкой work/Persona. Выполни по порядку:

1. Проверь, что я авторизован в GitHub (gh auth status). Если нет,
   остановись и скажи мне.

2. Проверь, что index.html лежит прямо в work/Persona, а не во вложенной
   папке. Если не так, скажи, что не так, и предложи исправить.

3. Предложи имя репозитория (например, persona) и предупреди, что он будет
   публичным: его увидит любой, а на странице могут быть моё имя и фото.
   Дождись моего подтверждения.

4. Если в work/Persona ещё нет git, инициализируй его. Сделай коммит со
   всеми файлами страницы, создай публичный репозиторий на GitHub и
   отправь всё в ветку main.

5. Включи GitHub Pages для этого репозитория: публикация из ветки main,
   папка / (root).

6. Проверь, что первая сборка Pages действительно запустилась. Если сборок
   нет совсем, сделай пустой коммит и отправь его ещё раз: первая сборка
   иногда не стартует сама.

7. Дождись, пока страница начнёт открываться, и покажи мне живую ссылку
   крупно.

Если на каком-то шаге ошибка, не иди дальше: объясни простыми словами,
что случилось, и предложи, что сделать.
```

Должно получиться примерно так:

```
✓ Репозиторий: github.com/твой-ник/persona
✓ GitHub Pages включён
https://твой-ник.github.io/persona/
```

Первая сборка занимает минуту-другую. Открыл ссылку, а там 404? Подожди минуту и обнови.
Не помогло, смотри [`../deploy-guide.md`](../deploy-guide.md), раздел «Если что-то пошло не так».

**Дальше всё само.** Каждое следующее изменение, которое агент отправит в `main`, через
минуту появится на живой ссылке. Попросил поправить страницу, сказал «закоммить и запушь»,
обновил вкладку.
